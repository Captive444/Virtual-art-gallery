# Проект: Виртуальная выставка искусств

## О проекте

Проект представляет собой виртуальную выставку искусств (SPA 2D панорама с функцие прокрутки), на которой представлены работы из музея. 

## Функции
- 2D просмотр панорамы + свайпы по горизонтали
- Просмотр коллекции работ
- Масштабирование изображений
- Переключение между языками (русский, английский)
- Перемотка работ с помощью слайдера

## Технологии

- HTML
- CSS
- JavaScript
- Swiper.js

## Установка

Чтобы запустить проект локально, следуйте этим шагам:

1. Клонируйте репозиторий: `git clone https://github.com/your-username/art-gallery.git`
2. Откройте файл `index.html` в браузере (желательно Fully Kiosk Browser или через локальный сервер)

## Использование

- Главная панорама прокручивается по циклу автоматически с помощью функций js 
- Работы подсвечиватся по клику осуществляется переход на детальную страницу экспоната (страница формируется из json файла)
- Нажмите на работу, чтобы увеличить ее размер
- Нажмите на кнопку закрытия, чтобы выйти из увеличенного режима
- Нажмите на кнопку переключения языков, чтобы переключиться между русским и английским языками

## Создание и разработка

Проект создан с использованием HTML, CSS и JavaScript. Для правки проекта используйте редактор кода вашего выбора (например, Visual Studio Code).
